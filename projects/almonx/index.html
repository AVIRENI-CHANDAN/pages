Almonx Project Reference

Shared details page for the Almonx project. A premium men's boutique e-commerce platform built with a decoupled backend API and a modern server-rendered storefront, deployed on AWS Lightsail at almonx.in.

Status: Active Build Domain: E-Commerce Last Updated: May 27, 2026

Project Snapshot

  • Purpose

    Build a premium men's boutique storefront with full checkout, order management, and admin capabilities.

  • Primary Users

    End customers shopping for men's apparel, and store administrators managing catalog and orders.

  • Core Capability

    Product catalog with categories and variants + PayPal checkout + order lifecycle with email notifications + admin dashboard.

  • Design Principle

    Clean premium aesthetic, fast page loads via SSR, and reliable transactional emails for every order state change.

Domain Entities

  • Product

    Catalog item with slug, brand, price, stock, images, variants, and reviews.

  • Category

    Hierarchical parent/child taxonomy for organizing products (e.g. Clothing > Shirts).

  • Order

    Purchase lifecycle: PENDING → PAID → PROCESSING → SHIPPED → DELIVERED, with cancel and refund paths.

  • Contact Message

    Customer support submissions categorized by issue type with OPEN/IN_PROGRESS/RESOLVED status.

  • User + Role

    CUSTOMER and ADMIN roles. Gmail dot normalization ensures consistent identity.

Tech Stack

Backend

  • Runtime

    Node.js + Express 5

  • Database

    MySQL with Prisma 6 ORM

  • Authentication

    JWT (access + refresh tokens) with bcrypt password hashing

  • Payments

    PayPal REST API (sandbox/live toggle via PAYPAL_MODE env)

  • Email

    Nodemailer + Gmail SMTP with app password

Frontend

  • Framework

    Next.js 16 with App Router and Turbopack

  • Language

    TypeScript

  • Styling

    Tailwind CSS with premium serif/gold aesthetic

  • Deployment

    AWS Lightsail, Nginx reverse proxy, PM2 process manager

  • Domain

    almonx.in (single-domain, path-based routing: /api → backend)

System Flow

1

Browse

Customers explore products by category, search, or featured picks on the storefront.

2

Checkout

Add to cart, enter shipping address, and complete payment via PayPal.

3

Fulfill

Admin reviews orders, updates status through PROCESSING → SHIPPED → DELIVERED.

4

Notify

Automated emails at every status change: confirmation, shipped, delivered, cancelled, refunded.

Operational Notes

  • Shipping

    Flat rate $15 shipping on all orders. No free shipping tier.

  • Gmail Normalization

    Dots are stripped from Gmail addresses before storage to prevent duplicate accounts (a.b@gmail.com = ab@gmail.com).

  • Security

    JWT auth with refresh tokens. Admin routes protected by role middleware. Password reset via time-limited email tokens.

  • PayPal Mode

    Controlled by PAYPAL_MODE env var. Currently sandbox on production until real products are loaded.

Infrastructure

Nginx Routing (almonx.in)

  • /api/*

    Reverse proxy to Express backend on port 5000

  • /uploads/*

    Static file serving from backend uploads directory

  • /*

    Reverse proxy to Next.js frontend on port 3000

  • SSL

    HTTPS via Let's Encrypt with HTTP → HTTPS redirect

Environment Variables

  • Backend .env

    DATABASE_URL, JWT_SECRET, PAYPAL_CLIENT_ID, PAYPAL_CLIENT_SECRET, PAYPAL_MODE, SMTP_USER, SMTP_PASS, ADMIN_EMAIL, CLIENT_URL

    NEXT_PUBLIC_API_URL (/api for production, http://localhost:5000/api for dev)

Current Build Plan

  • Phase 1
    Core storefront: product catalog, categories, cart, PayPal checkout, user auth with password reset.
  • Phase 2
    Admin dashboard: product CRUD with image upload, order management, contact message inbox.
  • Phase 3
    Transactional emails: order confirmation, shipping, delivery, cancellation, and refund notifications.
  • Phase 4
    Production hardening: real product catalog, live PayPal, analytics, and SEO optimization.
